## 特徴

- Pythonで開発

- pandasを用いたデータ分析


## ゲーム概要
Pythonで開発した英語学習用リズムゲームです

難易度は３種類から選べます
難易度の違いは以下の通りです

難易度	単語のハイライト	降ってくるノーツ
Easy	正解の前後 ±0.4秒 光る(かなり長め、見て合わせやすい)	表示される
Normal	正解の前後 ±0.12秒 だけ光る(一瞬だけ)	表示される
Hard	一切光らない	表示されない(レーンの線とヒットラインだけ)

50種類の文章を読み込ませております
10文ごとにそのまま続けるから止めるかを選択できます

ミスなどのプレイ実績はcsvに書き加えられ、データとして保存されます
データとしては以下の様なものが保存されます

## 保存されるデータ

- `played_at`：プレイ日時
- `session_id`：1回のプレイをまとめる識別番号
- `difficulty`：難易度
- `sentence_id`：文章番号
- `target_word`：タップ対象の単語
- `word_index`：文章内の単語位置
- `target_time`：正解のタイミング
- `tap_time`：実際に押した時刻
- `timing_error`：正解時刻との差
- `result`：PERFECT・GOOD・MISS

## analysisフォルダについて
analysisフォルダには以下の様な内容を分析し保存しております。(実際のプレイデータを使っております)。今後アップデートも予定しております
- 基本統計量
- PERFECT・GOOD・MISS割合
- タイミング誤差の分布
- 難易度別比較
- 単語の文字数と平均絶対誤差の関係
